# 座席配置最適化ツール（GUI版）

好き嫌いのアンケートから、「エネルギー的に一番落ち着く」座席配置を自動計算するツールです。
静電ポテンシャル（好き＝引力、嫌い＝反発）のアナロジーで座席を最適化します。

このフォルダの中だけで動作が完結する、GUI操作版です。CSVやコードを直接編集する必要はありません。

## 特徴

- **画面上でメンバーを追加・削除**しながら、お互いの好き嫌いスコア（-5〜+5）を表形式で入力できる
- **座席の□をマウスでドラッグ**して配置するだけで、座席同士の距離関係を設定できる（部屋の実際のレイアウトに合わせて自由に配置可能）
- 3つの計算モードを選べる
  - `net`：好き嫌いを単純に合算して計算する、最初に作られたシンプルなモデル
  - `split`：「好き」と「嫌い」を別の力として扱う。片思いの「嫌い」が相殺されて消えないよう改良されたモデル
  - `lexicographic`：「嫌い同士を離す」ことを最優先にしたうえで、その次に「好き同士を近づける」ことを狙うモデル
  - （3つとも独立した発想のモデルですが、多くの場合ほぼ同じ結論に収束します）
- 計算結果を**テキスト**と**座席配置図（見た目のイメージ）**の両方で確認できる
- 入力したデータ（メンバー・スコア・座席配置）を**保存・読込**できるので、次回起動時に続きから再開できる

## 動作環境

- Python 3（標準ライブラリのみ使用。追加インストール不要）
- `seat_gui.py` と `seat_optimizer.py` は**同じフォルダに置いて**使う（`seat_gui.py`が`seat_optimizer.py`を計算エンジンとして読み込むため）

## 使い方

### 1. 起動する

このフォルダ（`課題提出用`）の中で以下を実行するか、`seat_gui.py` をダブルクリックします。

```bash
python seat_gui.py
```

### 2. ①「好き嫌いを設定」でメンバーと好き嫌いを入力する

1. 「① 好き嫌いを設定...」ボタンを押すと、別ウィンドウが開きます
2. 「新しいメンバー名」に名前を入力して「＋ 追加」を押すと、メンバーが追加されます（人数分くり返す）
3. メンバーを消したいときは、その行の「－」ボタンを押します
4. 表に好き嫌いスコアを入力します。**行＝自分、列＝相手**です（例：Aの行のB列 ＝ AがBをどう思っているか）
   - `+5` に近いほど「好き」、`-5` に近いほど「嫌い」、`0` は「どうでもいい」
   - 自分自身の欄（対角線）は入力不要です
5. 入力し終わったら「OK」を押して確定します（「キャンセル」で変更を破棄できます）

### 3. ②「座席を設定」で座席の配置を決める

1. 「② 座席を設定...」ボタンを押すと、別ウィンドウが開きます
2. メンバーの人数と同じ数の□（座席）が自動で用意されます
3. □をマウスでドラッグして、実際の部屋の座席配置に近いレイアウトに動かします（□同士の距離が、そのまま座席間の距離として計算に使われます）
4. 「グリッドに整列」を押すと、初期の並びに戻せます
5. 配置が決まったら「OK」を押して確定します

### 4. 計算モードを選ぶ

`net` / `split` / `lexicographic` から選びます。迷ったら `lexicographic`（初期選択）でOKです。

### 5. 「最適化を実行」を押す

- 画面下に、計算にかかった時間・最適な座席配置がテキストで表示されます
- さらにその下に、座席配置図として結果が絵で表示されます（②で配置した位置に、割り当てられた人の名前が入ります）

### 6. データを保存する・続きから再開する

- 「保存...」を押すと、今のメンバー・好き嫌いスコア・座席配置・計算モードをファイルに保存できます
- 次回起動したときは「読込...」で保存したファイルを選ぶと、続きから再開できます
- 保存先は既定で `saved_data` フォルダです。実名や個人の好き嫌いを含むデータのため、このフォルダはGitHubにはアップロードされません（`.gitignore`で除外済み）
