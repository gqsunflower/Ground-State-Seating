# 座席配置最適化ツール（GUI版）

メンバー同士の好き嫌いのデータから、「エネルギー的に一番落ち着く」座席配置を自動計算するツールです。
静電ポテンシャル（好き＝引力、嫌い＝反発）のアナロジーで座席を最適化します。

GUI操作だけで完結するツールです。CSVやコードを直接編集する必要はありません。

## 想定する使い方

このツールは、**管理職などの立場の人が、普段のメンバーの様子を見て**「①メンバーの登録とその相性を設定」に好き嫌いスコアを入力することを前提にしています。

メンバー本人にアンケートを取って各自に直接スコアを入力させる用途は想定していません。誰が誰を嫌っているかという情報は、本人にとって見られたくない機微な情報になりうるためです。入力したデータの取り扱い（保存先を`.gitignore`で除外するなど）についても、この前提に基づいています。

## 特徴

- **画面上でメンバーを追加・削除**しながら、お互いの好き嫌いスコア（-5〜+5）を表形式で入力できる
- **座席の□をマウスでドラッグ**して配置するだけで、座席同士の距離関係を設定できる（部屋の実際のレイアウトに合わせて自由に配置可能）
- 3つの計算モードを選べる
  - `net`：好き嫌いを単純に合算して計算する、最初に作られたシンプルなモデル
  - `split`：「好き」と「嫌い」を別の力として扱う。片思いの「嫌い」が相殺されて消えないよう改良されたモデル
  - `lexicographic`：「嫌い同士を離す」ことを最優先にしたうえで、その次に「好き同士を近づける」ことを狙うモデル
  - （3つとも独立した発想のモデルですが、多くの場合ほぼ同じ結論に収束します）
- 計算結果を**座席配置図（見た目のイメージ）**とスコアの概要で確認できる
- 入力したデータ（メンバー・スコア・座席配置）を**保存・読込**できるので、次回起動時に続きから再開できる
- 結果を**PDFに出力**して、印刷したり配布したりできる

## 動作環境

- Python 3
- PDF出力機能を使う場合のみ、`reportlab` が必要（日本語のメンバー名を正しく表示するため）
  ```bash
  pip install reportlab
  ```
  それ以外の機能（メンバー登録・座席配置・最適化の実行・保存/読込）は標準ライブラリのみで動作し、追加インストールは不要です。

## 使い方

### 1. ダウンロードする

このリポジトリを丸ごとダウンロードします。

- GitHub上の緑色の「Code」ボタン →「Download ZIP」→ 好きな場所に展開(解凍)する
- または `git clone https://github.com/gqsunflower/Ground-State-Seating.git`

展開すると、以下のようなフォルダ構成になります。

```
Ground-State-Seating/
├── seat_gui.py         ← これを実行する
├── seat_optimizer.py   ← 計算エンジン本体(seat_gui.pyが自動で読み込む)
├── sample_data/
├── README.md
├── CLAUDE.md
└── .gitignore
```

`seat_gui.py` と `seat_optimizer.py` は**同じフォルダに置いたまま**にしてください（`seat_gui.py`が`seat_optimizer.py`を計算エンジンとして読み込むため、離すと動きません）。

### 2. 起動する

ダウンロードしたフォルダの中で `seat_gui.py` をダブルクリックするか、そのフォルダで以下を実行します。

```bash
python seat_gui.py
```

### 3. ①「メンバーの登録とその相性を設定」でメンバーと好き嫌いを入力する

1. 「① メンバーの登録とその相性を設定...」ボタンを押すと、別ウィンドウが開きます
2. 「新しいメンバー名」に名前を入力して「＋ 追加」を押すと、メンバーが追加されます（人数分くり返す）
3. メンバーを消したいときは、その行の「－」ボタンを押します
4. 表に好き嫌いスコアを入力します。**行＝自分、列＝相手**です（例：Aの行のB列 ＝ AがBをどう思っているか）
   - `+5` に近いほど「好き」、`-5` に近いほど「嫌い」、`0` は「どうでもいい」
   - 自分自身の欄（対角線）は入力不要です
5. 入力し終わったら「OK」を押して確定します（「キャンセル」で変更を破棄できます）

### 4. ②「座席を設定」で座席の配置を決める

1. 「② 座席を設定...」ボタンを押すと、別ウィンドウが開きます
2. メンバーの人数と同じ数の□（座席）が自動で用意されます
3. □をマウスでドラッグして、実際の部屋の座席配置に近いレイアウトに動かします（□同士の距離が、そのまま座席間の距離として計算に使われます）
4. 「グリッドに整列」を押すと、初期の並びに戻せます
5. 配置が決まったら「OK」を押して確定します

### 5. 計算モードを選ぶ

`net` / `split` / `lexicographic` のいずれかのトグルを選びます。それぞれの右に説明が書かれています。迷ったら `lexicographic`（初期選択）でOKです。

### 6. 「最適化を実行」を押す

- モード・スコア・計算時間の概要が1行で表示されます
- その下の「結果(座席配置図)」に、④で配置した位置に割り当てられた人の名前が入った図が表示されます（配置が大きいときは枠内のスクロールバーで確認できます）

### 7. 結果をPDFに出力する

- 「結果をPDFに出力...」ボタンを押すと、直近の実行結果（最適配置・座席配置図）をPDFファイルとして保存できます
- 初回は `pip install reportlab` が必要です（未インストールの場合はボタンを押すとその旨のメッセージが表示されます）

### 8. データを保存する・続きから再開する

- 「保存...」を押すと、今のメンバー・好き嫌いスコア・座席配置・計算モードをファイルに保存できます
- 次回起動したときは「読込...」で保存したファイルを選ぶと、続きから再開できます
- 保存先は既定で `saved_data` フォルダです。実名や個人の好き嫌いを含むデータのため、このフォルダはGitHubにはアップロードされません（`.gitignore`で除外済み）
